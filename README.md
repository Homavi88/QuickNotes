## 2. Цель

Приложение **QuickNotes** для быстрых заметок по проектам.

Сценарий: я веду несколько проектов, мысли и идеи появляются внезапно. Я нажимаю глобальный хоткей, выбираю проект, пишу текст, нажимаю `Ctrl+Enter`, окно исчезает. Запись сохранена в нужном проекте, я продолжаю работу. Весь цикл должен занимать 2-3 секунды.

Главный принцип: **скорость и надёжность**. Заметка не должна потеряться ни при каких обстоятельствах.

## 4. Окна

### 4.1. Окно быстрого ввода (label: `quick`)

**Параметры окна:**
- Размер около 520x260, не изменяемый пользователем
- Без рамки (`decorations: false`), прозрачный фон (`transparent: true`)
- По центру экрана (лучше на мониторе, где сейчас курсор мыши)
- Всегда поверх остальных (`alwaysOnTop`)
- Не показывается в панели задач (`skipTaskbar`)
- Создаётся скрытым при старте приложения и **не пересоздаётся**: только `show()` / `hide()`, чтобы появление было мгновенным
- Эффект стекла (acrylic или mica через window effects Tauri) и запасной вариант (полупрозрачный фон с блюром средствами CSS), если эффект недоступен

**Элементы интерфейса:**
- Кастомный выпадающий список проектов: цветная метка, эмодзи, название, подсказка с номером (`Ctrl+1`)
- Многострочное поле ввода, автофокус при каждом появлении окна
- Нижняя панель с подсказками клавиш: `Ctrl+Enter` сохранить, `Esc` закрыть
- Счётчик символов (ненавязчивый)

**Горячие клавиши внутри окна:**

| Клавиша | Действие |
|---|---|
| `Ctrl+Enter` | Сохранить заметку и скрыть окно |
| `Esc` | Скрыть окно без сохранения (см. черновик ниже) |
| `Ctrl+1` ... `Ctrl+9` | Быстро выбрать проект по номеру |
| `Ctrl+↑` / `Ctrl+↓` | Переключить проект |
| `Ctrl+P` | Открыть список проектов с поиском |

**Поведение:**
- Плавное появление (fade + лёгкий scale, 150-200 мс) и плавное скрытие
- Окно скрывается при потере фокуса (настраиваемо, по умолчанию включено)
- **Черновик:** если я нажал `Esc` или окно скрылось при потере фокуса, а текст не пустой, он сохраняется как черновик и восстанавливается при следующем открытии. После успешного сохранения черновик очищается. Заметка не должна пропасть из-за случайного клика мимо.
- После сохранения короткая анимация подтверждения (галочка, ~400 мс), затем окно скрывается
- Если сохранить не удалось: окно **не закрывается**, текст остаётся, показывается понятная ошибка
- Последний выбранный проект запоминается и подставляется при следующем открытии

### 4.2. Главное окно (label: `main`)

Окно с боковой панелью навигации. Размер по умолчанию около 1000x680, положение и размер запоминаются.

**Раздел «Заметки»:**
- Слева список проектов (цвет, эмодзи, название, количество заметок)
- Справа заметки выбранного проекта карточками, сгруппированными по дням («Сегодня», «Вчера», дата)
- Поиск по тексту: по всем проектам или только по выбранному (переключатель)
- Подсветка найденного фрагмента
- Редактирование заметки (inline) и удаление (с подтверждением и возможностью отмены в течение нескольких секунд)
- Кнопка копирования текста заметки
- Кнопка «Открыть файл проекта в проводнике»

**Раздел «Проекты»:**
- Добавить, переименовать, удалить (с предупреждением, что делать с файлами: оставить на диске или удалить)
- Выбор цвета (палитра 10-12 приятных цветов) и эмодзи
- Изменение порядка перетаскиванием

**Раздел «Настройки»:**
- Глобальный хоткей (запись нового сочетания, проверка на занятость)
- Автозапуск с Windows (вкл/выкл)
- Тема: тёмная / светлая / системная
- Акцентный цвет
- Папка хранения заметок (выбор через диалог)
- Скрывать окно быстрого ввода при потере фокуса
- Эффект стекла вкл/выкл

**Поведение:**
- Закрытие крестиком **сворачивает в трей**, приложение не завершается
- Завершение только через пункт «Выход» в меню трея

## 6. Хранение данных

### 6.1. Заметки

- Корневая папка по умолчанию: `%USERPROFILE%\QuickNotes\` (можно изменить)
- Структура: `QuickNotes\<Имя проекта>\notes.md`
- Новые записи добавляются **в конец файла**
- Формат записи:

```markdown
## 2026-11-26 05:52
Текст заметки, может быть многострочным.

- Кодировка UTF-8 (без BOM), переводы строк `\n`
- Если текст заметки сам содержит строки, начинающиеся с `## YYYY-MM-DD HH:mm`, их нужно экранировать при записи, чтобы парсер не принял их за новую заметку (придумай и опиши способ, например, добавление нулевой ширины пробела или обратного слеша), и корректно разэкранировать при чтении
